Young Images bei Netcup einrichten

Git-Deployment, MySQL/MariaDB und CMS-Setup – Schritt für Schritt.

Vor dem Start

  • Das GitHub-Repository lautet brechtgithub/testapp01; der aktuelle Branch heißt main.
  • Bei Netcup existiert bereits eine MySQL-/MariaDB-Datenbank.
  • Die Datenbank-Zugangsdaten gehören ausschließlich in die Datei .env. Sie dürfen weder nach GitHub hochgeladen noch im Chat geteilt werden.
  • Das Projekt benötigt PHP 8.1 oder neuer und die Erweiterung pdo_mysql.
Wichtig: Die lokale .env ist absichtlich von Git ausgeschlossen. Sie wird beim Git-Deployment nicht auf Netcup übertragen und muss dort manuell erstellt werden.

1. GitHub-Repository in Netcup verbinden

  1. Bei Netcup im Customer Control Panel anmelden.
  2. Unter Produkte das Webhosting-Paket auswählen und das Webhosting Control Panel öffnen.
  3. Die Domain youngimages.movez.de auswählen und den Bereich Git öffnen.
  4. Repository hinzufügen wählen.
  5. Als Remote-URL ausschließlich Folgendes eintragen: 
    https://github.com/brechtgithub/testapp01.git
    Keine eckigen Klammern, keinen Markdown-Link und kein movez.de@ verwenden.
  6. Den Branch main auswählen und das Repository hinzufügen.
  7. Als Deployment-Ziel den Ordner wählen, aus dem die URL /youngimages2026/ ausgeliefert wird. Dort müssen danach config.php, index.php und der Ordner admin liegen.
  8. Deploy / Bereitstellen klicken. Optional die automatische Bereitstellung bei neuen Commits aktivieren.
Falls das Repository privat ist, wird ein GitHub Personal Access Token mit Zugriff Contents: Read-only auf genau dieses Repository benötigt. Bei einem öffentlichen Repository ist kein Token notwendig.

2. Datenbank-Zugangsdaten auf Netcup hinterlegen

  1. Im Webhosting-Control-Panel den Dateimanager öffnen.
  2. Zum Deployment-Ordner wechseln, also zum Ordner mit config.php.
  3. Eine neue Datei namens .env erstellen. Falls der Dateimanager Dateien mit führendem Punkt nicht direkt anlegen kann: zunächst env.txt anlegen und danach in .env umbenennen.
  4. Die Werte aus den Netcup-Datenbankdetails eintragen:
DB_HOST=DEIN_DATENBANK_HOST
DB_PORT=3306
DB_NAME=DEIN_DATENBANKNAME
DB_USER=DEIN_DATENBANKBENUTZER
DB_PASSWORD=DEIN_DATENBANKPASSWORT
DB_CHARSET=utf8mb4
Sicherheitsregel: Platzhalter ersetzen, aber diese Datei nicht committen. Der Webserver muss sie lesen dürfen; öffentlich abrufbar ist sie durch die Projektkonfiguration gesperrt.

3. Datenbanktabellen anlegen

Es gibt zwei gleichwertige Wege. Weg A ist der übersichtlichste.

Weg A: SQL-Datei mit phpMyAdmin importieren

  1. Im Netcup-Control-Panel die Datenbankverwaltung bzw. phpMyAdmin öffnen.
  2. Die bereits angelegte Young-Images-Datenbank auswählen.
  3. Den Menüpunkt Importieren öffnen.
  4. Diese Projektdatei auswählen: database/youngimages_schema.sql.
  5. Import starten. Danach müssen zehn Tabellen vorhanden sein, darunter admins, settings, pages und projects.

Weg B: automatisch durch das Setup

Wenn .env korrekt eingerichtet ist, legt der erste Aufruf von admin/setup.php die Tabellen automatisch an. Ein vorheriger SQL-Import ist dann nicht nötig.

4. PHP-Version und CMS einrichten

  1. In Plesk für die Domain die PHP-Einstellungen öffnen und PHP 8.1, 8.2, 8.3 oder 8.4 wählen.
  2. Im Browser die Setup-Adresse öffnen: 
    https://youngimages.movez.de/youngimages2026/admin/setup.php
  3. Einen Admin-Benutzernamen und ein sicheres Passwort mit mindestens zehn Zeichen anlegen.
  4. Anschließend über /youngimages2026/admin/login.php anmelden.
  5. Nach dem ersten Admin-Login die Datei admin/setup.php auf dem Server löschen oder per Zugriffsschutz sperren.
Erfolgskontrolle: Im Adminbereich sollten Seiten, Arbeitsfelder, Projekte, Team, Förderer und weitere Beispielinhalte sichtbar sein.

Fehlerbehebung bei „500 Internal Server Error“

PrüfungLösung
.env fehlt oder liegt im falschen OrdnerDie Datei muss direkt neben config.php liegen und Werte für DB_NAME sowie DB_USER enthalten.
Falscher Datenbank-Host oder falsches PasswortDatenbankdetails im Netcup-Control-Panel mit der .env vergleichen. Passwort nie in Fehlermeldungen oder Chats posten.
PHP-Version ist zu altIn den PHP-Einstellungen mindestens PHP 8.1 auswählen.
could not find driverPHP-Erweiterung pdo_mysql aktivieren bzw. Netcup-Support kontaktieren.
Access deniedDatenbankname, Benutzer und Passwort prüfen; der Datenbankbenutzer braucht Rechte auf diese Datenbank.
Connection refused oder TimeoutDen von Netcup angegebenen Datenbank-Host verwenden, nicht zwingend localhost.

Für die genaue Ursache in Plesk den Bereich Logs / Protokolle der Domain öffnen und die jüngste PHP-Fehlermeldung prüfen. Zugangsdaten vor dem Teilen entfernen.
